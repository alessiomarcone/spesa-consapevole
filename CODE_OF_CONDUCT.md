# Code of conduct

We want this project to be useful to people with different budgets, diets,
household structures and technical experience. Be respectful, discuss evidence
instead of people and avoid assumptions about what someone should buy or eat.

Do not post credentials, addresses, voucher identifiers, private order history
or other personal data. Maintainers may remove content that creates a privacy or
security risk, as well as harassment, threats, discrimination or sustained
disruption.

Report sensitive security concerns through GitHub private security advisories.
For conduct concerns, contact the repository owner privately through their
GitHub profile. Reports will be reviewed confidentially and proportionately.
